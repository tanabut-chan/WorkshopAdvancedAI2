Frequently asked questions

What is Horizon?

add
Horizon is a modern cloud environment that empowers teams to generate fully featured web interfaces, database schemas, and workflows purely via AI dialogue and semantic directions.

How does Horizon work?

add
By inputting a natural language blueprint, our compiler structures the component architectures, spins up isolated node databases, generates API routers, and pushes the final package to the global CDN edge.

Can I export my code?

add
Yes. You own everything created inside Horizon. You can download your project bundles containing standard assets, component configurations, and data layers at any point with no licensing fees.

Is there a free trial?

add
We offer a comprehensive Standard plan that is completely free of charge. You can construct up to 3 projects, configure basic nodes, and test them with live preview addresses.

How secure is my data on Horizon?

add
Security is central to our engineering. All data nodes are fully sandboxed, encrypted with AES-256 at rest, and transport routes require strict SSL protocol handshakes.

Can I collaborate with my team in real-time?

add
Yes, Horizon workspaces are fully synchronized. Your team members can make changes, debug data routes, configure parameters, and inspect deployments side-by-side in real-time.
